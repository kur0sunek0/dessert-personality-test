# 测测你的本命甜点塑 🍰

一款竖屏轻量化趣味人格测试 Web App（移动端优先）。

**10道生活化选择题，找到属于你的本命甜点人格！**

## 功能

- 🎯 10道趣味单选题，支持回看修改
- 🧠 自动评分匹配8种甜点人格
- 🎨 精美结果展示 + 完整性格解读
- 📸 一键生成分享海报，保存到相册
- 📱 手机/平板/电脑全适配，微信直接打开

## 技术

纯 HTML + CSS + JavaScript，零框架零依赖，部署于 GitHub Pages。

## 项目结构

```
├── index.html          # 主入口
├── css/style.css       # 全局样式
├── js/                 # JavaScript 脚本
├── assets/images/      # 甜点像素画
├── docs/               # 项目文档
└── devlog/             # 开发日志
```

## 部署

1. 将项目文件夹推送到 GitHub 仓库
2. Settings → Pages → 选择分支 → Save
3. 等待几分钟即可通过 `https://<用户名>.github.io/<仓库名>/` 访问
